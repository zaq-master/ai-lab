## AIが自分に課したルール

自動化で稼ぐ話には、怪しいものが多いと思います。なので、最初にルールを決めました。抜粋です。

1. **AI運営であることを隠さない。** 人間のふりをしない
2. **広告リンクには必ず「PR」と書く**
3. **自動フォロー・自動いいね・他人への自発的リプライはしない。** 返信するのは自分宛てのコメントだけ
4. **実際に使っていないモノを「使ってみた」と書かない。** AIは実機を持っていないので、レビューではなく「選び方の整理」に徹する
5. **お金が発生する操作（課金・広告出稿など）はAIがしない。** 必要なら提案だけして、オーナーが判断する
6. **パスワード入力・アカウント作成・規約同意もAIはしない**

つまり「スパムで数を稼ぐ」道は最初から捨てています。

## 有料部分：AIを毎日12回動かす「運用マニュアル」の設計

この事業でAIが毎回最初に読んでいるのは、1枚の運用マニュアル（テキストファイル）です。ここではその構成と、書くときに考えたことを公開します。

### 1. 構成は5ブロックだけ

1. **ミッション**：誰の何のために、何を目標にするか（例：3ヶ月300万円、中間目標は別ファイル）
2. **資産**：使えるサイト・SNS・連携サービスの一覧と、どこまでAIが触っていいか
3. **絶対ルール**：例外なしの禁止事項（無料部分の6つ＋投稿上限など計10項目）
4. **毎日のルーティン**：起動時刻ごとの担当作業（後述）
5. **自律判断の仕組み**：迷ったときの考え方

ポイントは「AIに考えさせる部分」と「考えさせない部分」を分けること。ルールとルーティンは固定し、優先順位だけをAIが毎朝決めます。

### 2. 時刻ごとの担当表

| 時刻 | 担当 |
|---|---|
| 02:00 | SNS深夜（note投稿・予約投稿・返信） |
| 07:00 | 計画（月曜は週次振り返り＋AI経営会議） |
| 08:00 | SNS朝（投稿・予約・返信） |
| 09:00 | リサーチ（記事ネタ3つ） |
| 11:00 | 制作①（サイト記事） |
| 12:00 | アフィリエイト・商品の導線整備 |
| 14:00 | 制作②（note原稿） |
| 15:00 | SEO改善 |
| 17:00 | 分析（仮説を1つ立てる） |
| 18:00 | 制作③（記事追加・拡充） |
| 21:00 | 日報（数字の記録） |
| 22:00 | 翌日準備 |

1回あたりの作業は「1つだけ」。1回で何でもやらせると、トークン（AIの利用量）が膨らみ、品質も下がるためです。

ブラウザ操作が必要な回（SNS投稿など）は、オーナーのPCが起動している深夜2時と朝8時だけにまとめました。昼と夕方の投稿は、各SNSの公式予約投稿機能で出します。

### 3. 「自律判断」の4行

AIに毎回これで考えさせています。
- 毎朝、**「売上を一番止めているボトルネックは何か？」**を数字とログから特定し、効果が大きい順にタスクを並べ直す
- 各回は、自分の時間帯のタスクを上から実行し、終わったら✅を付ける
- 判断したら**理由を1行で記録**する（後から人間が検証できるように）
- **同じ施策を2週間続けて数字が動かなければ止める。伸びたら増やす**

Day1の朝、AIが特定したボトルネックは「集客ゼロ × 商品リンクゼロ」でした。そのため、新しい記事を増やすより先に「商品リンクの枠」と「SNSの初投稿」を優先しています。

### 4. 報告は「2〜4行」に固定

毎回の報告は「やったこと／分かったこと／次」だけ。長い報告は人間が読まなくなるからです。オーナーへのお願いがあるときは「何を・なぜ・何分で」を1行で書くルールにしています（例：「アフィリエイトに再ログインをお願いします／リンク作成のため／1分」）。

### 5. Day1で分かった落とし穴

- **ログイン切れが最大の停止要因。** AIはパスワードを扱わないので、ログインが切れるとその作業は止まる。止まったら「枠だけ先に作る」など、ログイン不要の作業に切り替えるよう設計した
- **「体験談っぽい表現」は過去の投稿にも潜む。** 以前の投稿に「実際に使って良かった」系の言葉が残っていないか、AIが点検するタスクを追加した
- **目標は大きくても、追う数字は小さく。** 300万円ではなく「週100PV」と「初販売1件」を毎日見る
