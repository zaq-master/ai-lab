# 楽天ブラックフライデー 期間中の更新メモ 追記手順（5分）

対象：content/posts/rakuten-blackfriday-memo.md（公開URL：https://zaq-master.github.io/ai-lab/posts/rakuten-blackfriday-memo.html）
期間：2026-11-19（木）20:00 〜 11-25（水）1:59（楽天公式キャンペーンページで2026-11-16に確認済み）

## だれが・いつ
- 担当：毎日 08:00 の回（ブラウザを使わない回なら、11:00 制作①の回の最初の5分）。1日1回まで
- 追記日：11/19（20時以降の回のみ）〜11/24。11/25 以降は追記しない（1:59で終了するため）
- その日すでに追記済みなら（記事内に同じ日付があれば）何もしない

## 何を・どこで確認するか
- 確認先は**楽天の公式ページだけ**：
  - 公式キャンペーンページ https://event.rakuten.co.jp/campaign/point-up/blackfriday/
  - そこからリンクされた楽天公式の企画ページ（event.rakuten.co.jp ／ www.rakuten.co.jp 配下）
- 書いてよいもの：公式ページに書かれている「開催中の企画の名前」「企画の日時・時間帯」「エントリーが必要かどうか」など、ページの文言でそのまま確かめられる事実
- 書かないもの：
  - 価格、割引率、ポイント還元率・倍率、上限額（変わりやすく、誤りが読者の損になるため。推測・計算も禁止）
  - まとめサイト・SNS・ブログ・ショップ個別ページの情報
  - 「お得」「おすすめ」などの評価、体験談
- **確認できなければ、その日は書かない**（「特になし」「準備中」も書かない）。ページが開けない・内容が読み取れない日はスキップしてログに1行残すだけ

## どこに貼るか
記事末尾の `<!-- draft-template ... -->`（公開HTMLには出ない型）のすぐ下。

### 初回（最初の1件）だけ：この塊をまるごと貼る
期限タグ行・見出し・1件目の間に**空行を入れない**（空行があると、11/25以降の自動非表示が効かなくなる）。

```
<!-- blackfriday-2026-11 期間中の更新メモ -->
## 期間中の更新メモ（楽天公式で確認できたことだけ）
- **11/DD（曜）**：
  公式で確認した事実（1行）
  出典：[ページ名](公式ページのURL)（11/DD HH:MM 確認）
```

### 2件目から：最後の行の直後に3行を足す（空行なし）
```
- **11/DD（曜）**：
  公式で確認した事実（1行）
  出典：[ページ名](公式ページのURL)（11/DD HH:MM 確認）
```

- 1件＝「日付／公式で確認した事実（1行）／出典URL」の3行
- 新しい日付を下に足す（古い順）
- 冒頭の【PR】表記はすでにあるので追加不要

## 11/25 以降の自動切替（触らない）
- build.py の `EXPIRE["blackfriday-2026-11"] = "2026-11-25T01:59"` を過ぎると、`<!-- blackfriday-2026-11 ... -->` から始まる塊（空行まで）が自動で消え、「終了しました」の案内（`<!-- ended:blackfriday-2026-11 -->`）が出る
- 更新メモもこの塊に入っているので、期間後は自動で消える。手で消さなくてよい（ただし期限後の最初のbuild＋pushは必要）

