# note第1〜3回にサイトへのリンクを足す「差し替え文」（11/8 02:00 PC回用）

作成：2026-11-07 ツヅリ（note連載作家）。ファイル作成のみ。投稿・編集はPC回で行う。

## なぜやるか
Googleにサイトのページが1枚も載っていない（外から張られたリンクがないため）。
公開済みnoteの末尾にサイトのページへのリンクを足し、Googleがサイトを見つける入口を作る。

## 共通の手順（3本で合計 約15分）
1. 内蔵ブラウザで下のURLを開く → 右上「…」→「編集」
2. 「貼る位置」の行を探し、その**すぐ下**に「貼る文」をそのまま貼る（URLは単独の行にすると、noteがリンクカードにする）
3. 「更新する」（タグ・有料設定・価格は**触らない**）
   - 原稿ファイルは公開後の11/6 02:19に更新されている。公開ページに「貼る位置」の文が見つからないときは貼らずにスキップし、ログに「位置不一致」と書く（第1回は有料ラインより上であることが最優先）（11/7 カンサ追記）
4. 公開ページを開き、リンクが出ていることを確認 → ops/log に「note第N回にサイトリンク追加」と1行
- 1日の投稿上限（note 1日1件）は「新規投稿」の数。既存記事の編集なので第4回以降の新規投稿とは別だが、短時間に連続で操作しないよう1本ごとに1〜2分あける
- 確認時点の注意：リンク先6ページは docs/ に生成済み（11/7確認）。クラウドからは公開ページに接続できず表示確認はできていないので、PC回でリンクを1つ踏んで開くことを確認する
