### 手順（⏱ 目安25〜40分。この回の最初にやる）
1. IGを開き、「作成」（＋）→「投稿」（または「新規投稿」）を押す
   「新規投稿を作成」「コンピューターから選択」が出たら止まる。**「コンピューターから選択」は押さない**（OSのファイル選択が開いて操作できなくなる）
2. inject.md の (c1) を JS実行ツールで実行 → `input数=1以上` を確認。0なら inject.md の (c2) の順で探す
3. チャンクを流す：`ops/sns/ig_upload_kit/2026-11-05_marathon/01_part1.txt` を **Readで読み**、中身を inject.md の (a) の `DATA` に入れ、`NN`=01、`K`=1 にして JS実行ツールで実行
   - 01_part1〜part5 → 02 → 03 → 04 → 05 の順に**全25回**。返り値 `01 part1 len=40000` を毎回確認
   - 1回が長すぎてツールが失敗したら、そのpartを半分に分けて (a') 追記版で2回に分ける
   - JS実行ツールにはファイルを渡せないので、Readで読んだ文字列をそのままコードに入れる（改行を入れない）
4. inject.md の (a2) を実行 → 5行とも「part OK / 長さ … OK」。NGの行は、言われたpartだけ (a) で流し直す
5. inject.md の (b) を実行 → 返り値が `OK: 5枚を設定` か確認
6. 画面の文字を読み（get_page_text 等）、「切り取り」「次へ」が出て、サムネイルが5枚並んでいるか確認
   - 1枚しか入らない → inject.md (b) の下の「複数を選択」の手順
   - 何も起きない → inject.md の (d)（ドロップで渡す）を1回だけ試す
7. 「次へ」→「次へ」（フィルターは使わない）→ キャプション欄に、**docs/sns/ig/2026-11-05_marathon/index.html の「キャプション（一字一句このまま）」の枠内の文を、そのまま全文**貼る（Readで読む。言い換え・追記・ハッシュタグの追加はしない。冒頭の【PR】も含めて全部）
8. 「詳細設定」で **AIラベル（「AIで作成」等の表示）をON**
