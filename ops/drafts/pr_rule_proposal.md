ずれは2つ：**(a) 付けるかどうか**（リンク先に広告があるとき）と、**(b) 書く場所**（冒頭【PR】／文末 #PR）。

## 2. 提案する共通基準（1つ）

> **その投稿から、広告リンクのあるページへ読者を送るなら【PR】を付ける。場所は本文の1行目の先頭。**

「送る」に当たるもの（どれか1つでも当てはまれば【PR】）：
1. 本文に広告リンク（もしも・楽天・Amazon）がある
2. 本文にサイトURLを書いていて、そのページに広告リンクがある（サイトは現在、記事ページすべてに楽天リンクと冒頭の広告表示あり）
3. 「プロフィールのリンクから」「URLをコピーして開いて」など、広告リンクのあるページへ行くよう案内している（IGはURLが押せなくても同じ扱い）
4. 特定の商品・商品カテゴリを勧め、その買い先として広告ページにつながる（動画・画像の中で勧める場合も含む）

【PR】を付けないもの：
- 誘導先が無い・広告の無いページだけ（例：数字や失敗の実録、noteの無料回、広告リンクの無い自作ツール＝サブスク見直しチェッカー）
- 運営者自身の有料商品（note有料記事・テンプレ）だけへの案内 → 【PR】ではなく「運営者自身の有料記事の案内（アフィリエイトではありません）」と書く（ops/decisions.md 2026-11-03 10:00 の既存ルールのまま）

書き方（両媒体共通）：
- **X**：1行目の先頭に「【PR】」。文末の「#PR」だけにはしない。
- **Instagram（フィード・リール）**：キャプション1行目の先頭に「【PR】」（「続きを読む」で隠れない位置）。あわせて誘導の行に「リンク先の記事には楽天の商品リンク（広告）があります」を1行。リールは可能なら動画の最初の画面にも「PR」を小さく入れる。
- 迷ったら付ける（付けすぎて困ることはほぼ無いが、付け忘れはステマ規制・ASPの規約の両方で問題になりうる）。

## 3. この基準にした理由

- **安全側**：「投稿内に広告リンクが無ければ不要」だと、読者を広告ページへ送る目的の投稿でも広告だと分からないまま届く。いまの投稿の目的は記事の楽天リンクから買ってもらうことなので、送る側の投稿にも広告だと分かる印を付けておくほうが、ステマ規制の趣旨（広告なのに広告と分からない表示をなくす）に沿う。
- **ステマ規制の一般的な考え方**（2023年10月施行、景品表示法の告示「一般消費者が事業者の表示であることを判別することが困難である表示」と消費者庁の運用基準として一般に紹介されている内容）：
  - 広告であることを「広告」「PR」などの分かりやすい言葉で示す
  - 冒頭など目に入る位置に置く。文末だけ・大量のハッシュタグの中・小さい文字などは「分かりにくい」例として挙げられることが多い → 文末「#PR」をやめ、1行目の先頭【PR】に統一
  - ※この規制が直接の対象とするのは広告主（事業者）で、アフィリエイト投稿がどこまで対象になるかは広告主の関与の度合いによる、と説明されることが多い。当アカウントの投稿が個別にどう判断されるかは**断定できない**。だからこそ付ける側に倒す。
- **ASP側**：もしもアフィリエイト・楽天の規約やガイドラインでも広告である旨の表示が求められている可能性が高いが、**最新の文面は未確認**（管理画面のログインが必要）。週1回のログイン依頼のときに確認したい。
- **運用が簡単**：判断が「誘導先に広告があるか」1つで済み、サイトの記事ページは全部広告ありなので「サイト記事へ送る投稿＝全部【PR】」と覚えればよい。
