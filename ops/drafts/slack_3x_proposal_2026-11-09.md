# 案：Slack自動報告を1日3回にする（CLAUDE.md 変更案・未適用）
作成：2026-11-09 23:10（自走回・今日の提案3）／根拠：AI経営会議 第2回（ops/meetings/2026-11-09.md）決定2の③
**オーナーの「③OK」が来るまで CLAUDE.md は変えない。** OKが来た回でこの差分をそのまま当てる。

## なぜ
- 今は毎時＋深掘りで、Slackへの自動投稿が1日35〜65件（会議の推定）。オーナーへの依頼①②（売上に一番近い）が埋もれて、11/4から返事が来ていない
- 依頼が読まれる形にするのが目的。作業そのものは減らさない（ログ ops/log/ には毎回これまでどおり書く）

## 変えること（3つだけ）
| いま | 変更後 |
|---|---|
| 毎時、#daily-report に「【HH:MM】…」を投稿 | **#daily-report は1日3回だけ**：07:00（今日の計画＋🙋依頼）／14:00（午前〜昼のまとめ）／21:00（日報） |
| 深掘りで各キャラが事業チャンネルに毎ラウンド投稿＋カンサとの掛け合い | 深掘り1回につき**最後に1投稿だけ**（画像付きの事業別報告は残す）。掛け合いは「数字やリスクの指摘がある時だけ」 |
| 毎時の回の報告は必須 | 毎時の回はログ追記だけ。ただし🔴（止まっている・失敗・オーナー判断が必要）の時は**その場で1件**投稿してよい |

変えないこと：毎時の「オーナーの書き込み確認と返事」、ログのpush、日報フォーマット、トークンの扱い。

## CLAUDE.md の書き換え箇所（案）
1. 「毎日のルーティン」冒頭
   - 旧：`（毎時1回・1日24回、毎回Slack #daily-report に短く報告）`
   - 新：`（毎時1回・1日24回。Slack #daily-report への報告は 07:00・14:00・21:00 の3回だけ。他の回は ops/log/ に追記するだけ。🔴のときだけその場で1件投稿）`
2. 同じ節の `各回の最後に必ず「【HH:MM】…」を2〜4行で投稿し、` → `各回の最後に「【HH:MM】…」を ops/log/YYYY-MM-DD.md に追記して push（07:00・14:00・21:00 はまとめて Slack にも投稿）。`
3. 「Slack報告のルール」の `各エージェントは自分の事業チャンネルで、毎回「報告・分析・次の方針」を出す` → `…深掘りセッション1回につき最後に1回だけ出す`
4. 「掛け合い」の `各ラウンドで` → `数字・リスクの指摘があるときだけ`
5. 定時タスクの指示文（scheduled task の手順5）も「07・14・21時以外は Slack 投稿なし」に合わせる必要あり → これはオーナー側の設定なので、OK後に変更方法を確認する

```
➡️ *次*
21時に日報
```
