# Notion版 サブスク管理＆見直しDB — 作り方（販売者用の手順書）

> 作成：電脳アリス（AI運営）／2026-11-02。Notionアカウントでの動作確認は**まだしていません**。「要確認」の箇所は、オーナーのNotion（無料プラン）で1回組み立てて確かめてから販売する。
> サンプル行のサービス名・金額はすべて架空です。

## 同梱ファイル
| ファイル | 中身 | Notionでの扱い |
|---|---|---|
| `subscriptions.csv` | 入力プロパティ9列＋架空サンプル10行（UTF-8・カンマ区切り） | インポートすると**データベース**になる |
| `サブスク管理_使い方.md` | 購入者向けの使い方ページ | インポートすると**ページ**になる |

## 調べて分かったNotionの仕様（2026-11-02 調査）
出典：Notion公式ヘルプ「Import data into Notion」https://www.notion.com/help/import-data-into-notion ／「Formula syntax & functions」https://www.notion.com/help/formula-syntax
- CSVをインポートすると新しいデータベースになる（行→ページ、列→プロパティ）。列ごとにどのプロパティ型にするか**自分で割り当てる**。型が混ざった列はデータ消失を避けるためテキストになることがある
- **新規CSVインポートでは数式（formula）・ロールアップ・リレーションは作れない** → 下の「STEP 3」で手で足す
- 既存DBへの「CSVとマージ（Merge with CSV）」は**行を追加するだけ**で、既存行は更新しない
- 文字化けしたら UTF-8 で保存し直す。日付は MM/DD/YYYY 形式で取り込まれる、とヘルプにあるため、CSVの日付は `04/10/2025` 形式にした
- 無料プランのCSV上限は5MB（このCSVは1KB未満）
- Markdown（.md）は1ページとして取り込める（見出し・リスト・コードブロック対応）

## STEP 1　CSVをインポート
1. Notion左下（またはサイドバー）の「インポート」→「CSV」→ `subscriptions.csv` を選ぶ
2. 列の型を次のように割り当てる（割り当て画面が出ない場合は、取り込み後に各列名をクリック→「プロパティの種類」で変更）

| 列 | 型 | 補足 |
|---|---|---|
| サービス名 | タイトル | 1列目がタイトルになる想定（**要確認**） |
| カテゴリ | セレクト | 動画／音楽／クラウド・ツール／ニュース・読書／健康・フィットネス／学習／ゲーム／生活・買い物／その他 |
| 支払周期 | セレクト | 「月額」「年額」の2つ。**表記を変えると数式が動かない** |
| 料金 | 数値 | 数値の形式＝「円」（なければ「数値（カンマ区切り）」） |
| 契約開始日 | 日付 | MM/DD/YYYY で入る想定。ずれたら日付形式を確認（**要確認**） |
| 支払方法 | セレクト | クレカ／キャリア決済 など |
| 月の利用回数 | 数値 | |
| 使っていない | チェックボックス | CSVの Yes/No がチェックに変換されるか**要確認**（されない場合はサンプル2行だけ手でチェック） |
| メモ | テキスト | |

## STEP 2　セレクトの色（任意）
支払周期：月額＝青、年額＝紫。カテゴリは自由。

## STEP 3　数式プロパティを7つ追加（Formula 2.0 の書式）
「＋」→ プロパティの種類「数式」→ 名前を付けて、下の式をそのまま貼る。**上から順に作る**（後の式が前の式を参照するため）。
※ `prop("…")` の中の名前は、プロパティ名と一字一句同じにする。

### ① 月額換算
```
if(prop("支払周期") == "年額", round(prop("料金") / 12), prop("料金"))
```
数値の形式＝円

### ② 年額換算
```
if(prop("支払周期") == "年額", prop("料金"), prop("料金") * 12)
```
数値の形式＝円

### ③ 次回更新日（契約開始日から周期ごとに自動で進む）
```
lets(
  start, prop("契約開始日"),
  step, if(prop("支払周期") == "年額", 12, 1),
  n, floor(dateBetween(today(), start, "months") / step),
  d, dateAdd(start, n * step, "months"),
  if(empty(start), start,
    if(dateBetween(start, today(), "days") >= 0, start,
      if(dateBetween(d, today(), "days") >= 0, d, dateAdd(d, step, "months"))))
)
```
- 考え方はExcel版と同じ：開始日が未来ならそのまま／過ぎていたら「開始日＋周期×n」を、今日以降になるまで1周期進める
- `dateBetween` が端数の月を切り捨てるかは公式ヘルプに記載がない（**要確認**）。切り捨てでも四捨五入でも、最後の「今日より前なら1周期足す」で今日以降の日付になる。ただし四捨五入の場合、1周期先の日付が出ることがあるので、サンプル「ニュースアプリE」などで結果を目視確認する

### ④ 更新まで（日）
```
if(empty(prop("次回更新日")), 0, dateBetween(prop("次回更新日"), today(), "days"))
```

### ⑤ 1回あたり料金（表示用テキスト）
```
if(prop("月の利用回数") > 0,
  format(round(prop("月額換算") / prop("月の利用回数"))) + "円",
  "未使用")
```

### ⑥ 判定（色付き）
基準値（500円・1回）はここで直接書き換える（Notion版は「設定シート」がないため）。
```
lets(
  uses, prop("月の利用回数"),
  per, if(uses > 0, prop("月額換算") / uses, 0),
  ifs(
    prop("使っていない") or uses == 0, style("解約候補", "b", "red", "red_background"),
    per >= 500 or uses <= 1, style("要見直し", "b", "orange", "orange_background"),
    style("継続", "green")
  )
)
```
- 月の利用回数が**空欄**のときの扱い（0とみなされて「解約候補」になるか）は**要確認**。なる場合は「使い方」ページに「回数は必ず入れる」と書いてあるので、そのままでよい
- `style()` の色名（"red_background" 等）が効かない場合は、`style()` を外して文字だけにする

### ⑦ 解約時の節約額（年）
```
if(prop("使っていない"), prop("年額換算"), 0)
```
数値の形式＝円

## STEP 4　合計とビュー
1. テーブル下端の「計算」から：月額換算＝合計、年額換算＝合計、解約時の節約額（年）＝合計、サービス名＝すべてカウント
2. ビューを3つ作る
   - 「一覧」：テーブル。並び替え＝更新まで（日）昇順
   - 「見直し」：テーブル。フィルター＝判定 が「継続」を含まない（数式のテキストでフィルターできるか**要確認**。できなければ「使っていない」がチェック＋利用回数≦1 の OR で代用）
   - 「カテゴリ別」：ボード（グループ＝カテゴリ）。カード下に月額換算を表示
3. 「次回更新日」でカレンダービューを追加すると、更新日が月の予定のように見える（任意）

## STEP 5　使い方ページと仕上げ
1. `サブスク管理_使い方.md` をインポート → ページを開き、最上部にこのデータベースを「リンクドビュー」で埋め込む（または使い方ページの中にDBを移動）
2. ページ名を「サブスク管理＆見直しDB（電脳アリス）」に
3. 右上「共有」→「Web公開」→「テンプレートとして複製を許可」をオン（**要確認**：無料プランでの表示名・場所。公開URLを有料エリアに貼る）
4. 公開設定・共有はオーナーのNotionアカウントで行う（AIはログインしない）
