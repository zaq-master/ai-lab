ページ構成：表紙・2027年カレンダー（給料日と支払日の色分け欄つき）・お金の目標・年間一覧・月の予算・給料ごとの予算・支払い管理表（請求18件×12ヶ月）・支出記録・週の支出記録・貯金目標（塗りつぶし式）・目的別積立（シンキングファンド）・借金返済の記録・買わないチャレンジ（30日）・月のふり返り。通貨記号は入れていない（どの国でも使える）。

## 選んだ理由（数字はRankHero＝第三者ツールの値。Etsy公式ではない）
- 「budget planner」の月間検索数は平均6.05万。2026年1月が最多の7.4万。中央値は$6.99、平均は$8.94、76%が$10未満。出品数は248,607件（[出典](https://www.rankhero.com/keywords/budget-planner)）
- 「expense tracker」の月間検索数は2.71万（1月は3.31万）、中央値は$7.99（[出典](https://www.rankhero.com/keywords/expense-tracker)）。「budget tracker」は1.48万（1月が最多で2.22万）、中央値は$8.99（[出典](https://www.rankhero.com/keywords/budget-tracker)）
- habit tracker と同じく1月に需要が伸びるので、年末前に出品するのが合っている。競合が多いため、タイトルに個別の管理表の名前（支出・貯金・借金・支払い）を並べ、細かい検索語でも見つかるようにした。

## 守っていること
- 金融の助言はしない。予算の決め方、返済方法のおすすめ、利息の計算は入れていない。記入欄と、1行の書き方メモ（例：支払ったら月の欄にチェック）だけにしてある。説明文にも「助言ではない」と書いた。
- AIが作った「手順書」は入れていない（Etsyの2026-10-22の新ルール対応）。AIの使用は説明文で開示している。
- フォント（Inter、Caladea、どちらもSIL OFL 1.1）とライセンスは第1弾と同じ。図形はすべてHTML/CSS/SVGで自作。
