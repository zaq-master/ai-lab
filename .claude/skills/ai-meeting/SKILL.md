# AI経営会議の型

## 1. 資料を用意（自分で読む）
ops/metrics.csv（直近7行）、先週の ops/log、ops/backlog.md、ops/decisions.md、前回の ops/meetings/

## 2. 3体を同時に起動（Agentツールを1メッセージで3回呼ぶ）
各プロンプトに「資料の要約（数字はそのまま）」「キャラ」「400字以内」「制約：お金を使わない・AI運営を隠さない・スパム禁止」を入れる
- 【数字担当】冷静。目標までの逆算、先週の達成率、今週の数値目標1つ
- 【辛口担当】遠慮なし。致命的な弱点3つ＋それぞれお金を使わない代案
- 【アイデア担当】ノリがいい。新しい稼ぎ方3つ＋今週やる1つ

## 3. まとめる（自分＝電脳アリス、司会・社長）
- 3者の意見を突き合わせ、決定事項を3つまで。前回の決定の結果も検証する（効いた／効かなかった）
- 2週間数字が動かない施策は止める判断をここでする

## 4. 出力
- ops/meetings/YYYY-MM-DD.md：会話形式の議事録（キャラは立てるが、内容は本物の判断）＋決定事項＋宿題
- ops/backlog.md を決定に合わせて作り直す、ops/decisions.md に【AI経営会議 第N回】として追記
- Slack #daily-report に要約（各担当1行＋決定事項）
- note原稿「AI経営会議 第N回」を note-article スキルの形式で作り #note に置く（投稿は翌02:00）
- Slackに会議用botが用意されていれば #ai経営会議 に各キャラとして発言を投稿
