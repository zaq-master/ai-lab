# パチンコ1万人シミュレーション動画の作り方

## いちばん大事な決まり
- **オーナーへの説明・報告はすべて日本語**。専門用語は使わず、使うときは括弧で言い換える（2026-11-18 オーナー指示）
- テストは**10秒**で見せる（トークン節約）。OKのあと本番
- 構成は `side/pachi3d/STRUCTURE.md`（ショート7パート／ロング10パート）、語り方・見た目の決まりは `side/pachi3d/PROMPTS.md`

## 1. ネタを決める
- 「パチンコ好きが『それ実際どうなの？』と思うこと」：作戦の検証（勝ったら帰る、ハマり台を狙う）、スペック比較（継続率×出玉、甘デジ vs ミドル）
- 候補と作ったものは `side/research/sim_channel_notes.md`。参考：確率シミュレーション大学（作戦の検証が伸びる）、だいいち!（「同じ○○ならどっち？」が伸びる）
- 実在機の数字は公開情報で確認し、出典を説明欄に。確認できない数字は使わない

## 2. シミュレーションと台本
- お手本：`side/sim1min/build.py`（縦ショート）、`side/pachi3d/build.py`（横ロング）
- 乱数の種は固定。数字は計算結果から自動で台本に入れる（手書きしない）
- 台本は語りかけ調：「〜ですよね？」「実は〜なんです」「結果は…」。1文1つのこと

## 3. 読みの点検（必ず）
- `side/pachi3d/yomi.py` の `to_say` → `check` で**全行のカナを表示し、自分で1行ずつ読む**
- 自動では見つからない誤読がある（例：大きすぎ→タイキスギ、「〜、は」→ハ）。見つけたら TABLE に足すか言い回しを変える
- 小数点は「点」に置き換え済み（テンと読む）

## 4. 声・BGM
- 声：Style-Bert-VITS2 小春音アミ（`side/pachi3d/sbv2_ja.py` の `tts_script`＝文ごとに調子・速さ・間を変える）。クレジット「Style-BertVITS2モデル: 小春音アミ、あみたろの声素材工房 (https://amitaro.net/)」
- 声のモデルは `voices_sbv2/`（リポジトリに入れない。無ければ huggingface_hub で litagin/sbv2_koharune_ami と ku-nlp/deberta-v2-large-japanese-char-wwm を取得）
- BGM：オーナーが手で落とした OpenTracks の曲（`side/pachi3d/assets/bgm/`、リポジトリに入れない）。無ければ自作の `bgm()`

## 5. 映像
- three.js＋HyperFrames。ショートは縦1080x1920、ロングは横1920x1080
- 見た目は毎回ネタにちなんで変える。実機・メーカー・アニメ・ネットの写真は使わない（許可がない限り）
- アリス：`assets/alice_v2/`（表情12枚）。場面ごとに表情を指定、口パク・まばたき
- 数字が出る瞬間に演出（ため→ドン、キラン音、紙吹雪など）

## 6. 確認と描き出し
- `npx --yes hyperframes@0.9.64 snapshot --at ...` で静止画を見て、文字の重なり・はみ出しを直す
- 10秒テスト：`render --start S --end S+10`。本番：`render -o renders/xxx.mp4`（時間がかかるので run_in_background）
- 完成後、長さ・音量・フレームを確認してからオーナーに送る

## 7. 仕上げ
- サムネ：大きな数字＋驚き顔のアリス＋短い一言（ショートは1080x1920、ロングは1280x720）
- description.txt：タイトル案（【数字】＋問い＋【機種名】＋#shorts）、AI制作の明記、条件、出典、「必勝法ではありません」「18歳未満は遊技できません」、BGM・音声のクレジット
- X告知文を `ops/vocalo/x_queue.md` に追記（3〜5行、数字1つ、ハッシュタグ3つまで、動画URLはアップ後に入れる）
- 曲・音声・声のモデル・動画はコミットしない。コードと説明文だけ push
- オーナーへ日本語で報告（やったこと／分かったこと／次）し、動画とサムネを送る

## やらないこと
- 「勝てる」「必勝」とあおる
- お金が発生する操作（有料プラン・課金）
- 他チャンネルのキャラ・見た目のまね（構成や手法だけ参考にする）
