# SNS・PC回の型

## 開始時チェック（1分）
1. built-in-browser スキルを読む。tabs_context で内蔵ブラウザに届くか確認。届かなければ「PCオフで未投稿」とSlack報告して終了
2. 各サービスのログイン状態を find/get_page_text で確認（スクショは使わない）。切れていたら、その作業は飛ばし、最後にまとめて「🙋 ◯◯に再ログイン（1分）」とオーナーに依頼

## 優先順（時間がなければ上から）
1. **もしもの商品リンク**：ログイン不要。`python3 ops/make_links.py` で空の枠を埋める（クラウド回でも可）
2. **note投稿**（02:00のみ）：note-article スキル
3. **X**：その回に1件投稿＋次の時間帯の分を公式の予約機能でセット（1日合計3件まで）
4. **Instagram**：1日1件。画像はHTML/SVGで作るか Canva の無料範囲で作る
5. **返信**：自分宛てのリプ・コメント・DMのみ。炎上・クレーム・お金・個人情報はSlackでオーナーへ

## 投稿の中身（役割分担：2026-11-03決定）
- **X（@qol_gadget_life）＝2026-11-06から「トガ feat. 電脳アリス」（AIボカロP）専用に切り替え**（オーナー決定）。ガジェット・AI実録の投稿はXではしない
  - 優先1：YouTubeに新しい動画が出たら告知（曲名・ひとこと・動画URL・#ボカロ #オリジナル曲 #電脳アリス）。新着の確認は毎時の回が https://www.youtube.com/@toga_alice/shorts をWebFetchで見て ops/vocalo/posted.md と照合し、未告知を ops/vocalo/x_queue.md に積む。PC回が投稿・予約する
  - それ以外のつぶやき：歌詞の一節、曲作りの本当の話（Sunoで何曲作って選んだか等、事実のみ）、次の曲の予告。1日3件まで
  - フォローは自動でしない（ルール3・Xの自動化ルール違反）。フォロー候補はオーナーに提案するだけ
  - プロフィール：名前「トガ feat. 電脳アリス」、自己紹介に「投稿はAIで自動運用」を必ず残す（ルール1）。YouTubeチャンネルURLを載せる
- **Instagram＝ガジェットの図解**：電気代早見表・選び方チャートなど保存したくなる1枚 → サイト記事へ誘導（記事の楽天リンクが売上）
- どちらにも「何の投稿か」が1行目で分かるようにする（例：X「【AI実録Day3】売上0円…」、IG「【保存版】足元暖房の電気代早見表」）
- 主軸は「AIが3ヶ月で300万円に挑む実録」：その日の数字、失敗、AIの判断。数字は ops/metrics.csv から
- 補助：サイト記事の早見表や計算式を切り出した図解（記事URLを添える）
- 広告リンクを含む投稿には「PR」を付ける。**共通基準（2026-11-04採用）**：その投稿から広告リンクのあるページ（サイトの記事・広告枠のあるツール）へ読者を送るなら、XもIGも本文1行目の先頭に【PR】。IGは誘導の行に「リンク先の記事には楽天の商品リンク（広告）があります」も1行。誘導先に広告が無い実録・note無料回・広告なしツールは不要。運営者自身の有料商品だけの案内は「運営者自身の有料記事の案内（アフィリエイトではありません）」。迷ったら付ける（詳細 ops/drafts/pr_rule_proposal.md）
- 禁止：自動フォロー・いいね、他人への自発的なリプ・引用、ハッシュタグの乱用、同じ文の連投

## 記録
ops/drafts/当日.md の下書きを使ったら✅。投稿URLを ops/log に残し、Slackに報告
- 投稿した実文（予約・プロフィール文・IGキャプションも含む）は、下書きと違っても一字一句そのまま ops/drafts/当日.md の「投稿の記録」欄に貼り、URL・時刻を添える。画像は、投稿した画像のファイル名を同じ記録欄に書く（リポジトリのストックから投稿した場合はそのパス、例：media/… や ops/drafts/ig_stock_…。PC回にブラウザのタブ内で作った画像はリポジトリに移せないので「タブ内で作成・未保存」と書く）
