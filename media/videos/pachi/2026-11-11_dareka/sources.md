# 出典・計算（2026-11-06 作成／11/11公開想定）
特定の機種・お店の数字は使っていない（一般的な確率の計算ネタ）。外部の数字なし＝出典URLなし。
既存8本（ヴァルヴレイヴ・1万円・シミュ18000・交換率・中央値〈319.7回までに約63%も既出〉・継続率・ハマり＝無記憶性・二項分布バラバラ）と重ならないテーマ：
「1人では珍しい大ハマりも、打つ人数が多いと“だれか”には起きる（少なくとも1人の確率＝1−(1−a)^n）」。

## 前提（画面に表示）
- 大当り確率 1/319.7 は計算用の例（画面に「（例）」「特定の機種の数字ではありません」）
- 1回転ごとの当たり確率は毎回同じ（独立）。「大ハマり」＝1500回まわして当たり0回。お金・出玉・回転率は考えない
- 各人は互いに無関係（独立）として計算

## 計算（Python で再計算＋モンテカルロ検算、詳細は check.log）
- 1人が1500回ハマる a＝(1−1/319.7)^1500＝0.910%（画面「約1%（約110人に1人）」、1/a＝109.9）
- n人中だれか1人以上＝1−(1−a)^n：1人0.91%／10人8.74%／50人36.69%／100人59.92%／300人93.56%（画面 約1・9・37・60・94%）
- 1000回ハマり：1人4.36%（「約4%」）／100人中の平均4.36人（「約4人」）／100人中だれか1人以上98.84%（「約99%」）
- モンテカルロ（seed=1、100人×2万回）：1500回 60.14%・1000回 98.70% → 理論値と一致。100万人で1人あたり 0.908%・4.327%
- 注：確率上の割合であって、実際の結果は台・お店・運によって変わる。「SNSの大ハマり報告も人数が多ければ出てきて当然」は上の計算から言える範囲の表現（SNSの実データは使っていない）
