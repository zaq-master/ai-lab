USB-C充電器の選び方｜W数・ポート数・GaNの意味を3分で理解する

充電器を何個もコンセントに挿していませんか？USB-C充電器を1台うまく選ぶと、机まわりも旅行の荷物もすっきりします。ここでは、買う前に見るべきポイントを順番にまとめます。

1. まず「何W必要か」を決める

充電器の出力（W＝ワット）は、つなぐ機器の中でいちばん電力を使うものに合わせて考えます。

機器の例 目安の出力
スマホ 20〜30W
タブレット 30〜45W
薄型ノートPC 45〜65W
高性能ノートPC 65〜100W以上

正確な数値は、使っている機器の公式サイトや付属充電器の表示で確認してください。足りないと「充電が遅い」「使いながらだと減っていく」状態になります。

2. 複数ポートは「合計」と「1ポートあたり」を両方見る

複数ポートの充電器でいちばん多い失敗がここです。

  • 合計出力：全ポートを同時に使ったときの上限
  • 1ポートあたりの最大出力：1台だけつないだときに出せる上限

たとえば「合計65W」でも、2台同時につなぐと配分が変わり、ノートPC側が想定より少なくなることがあります。商品ページにあるポートごとの出力配分表を必ず確認しましょう。

3. 規格は「USB PD」対応を選ぶ

ノートPCやiPhone・Androidの多くは、USB Power Delivery（USB PD）という規格で急速充電します。迷ったらPD対応と書かれたものを選べば大きく外しません。

4. GaN（窒化ガリウム）って何がいいの？

GaNは充電器の中に使われる半導体の素材です。従来品より小さく・発熱しにくく作りやすいのが特徴で、同じW数でもコンパクトな製品が増えています。持ち歩くならGaN採用モデルが有利です。

5. ケーブルも忘れずに

充電器が高出力でも、ケーブルが対応していないと性能が出ません。

  • 60Wを超える充電には、100W（5A）対応と書かれたケーブルが必要
  • 安すぎるノーブランド品は避け、対応W数が明記されたものを選ぶ

6. 安全面のチェック

  • 日本で販売される電源機器にはPSEマークの表示が必要です
  • 過電流・過熱保護などの記載があるかも確認しましょう

まとめ

  1. いちばん電力を使う機器に合わせてW数を決める
  2. 複数ポートなら配分表を見る
  3. USB PD対応、持ち歩くならGaN
  4. ケーブルの対応W数も合わせる
