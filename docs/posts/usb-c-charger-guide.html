USB-C充電器の選び方｜何W必要？ノートPCも充電できる？W数・ポート・ケーブル・PD/PPSをQ&Aで解説

結論：いちばん電力を使う機器に合わせてW数を決め、「USB PD対応」「ポートごとの配分表」「ケーブルの対応W数」の3つを確認すれば大きく外しません。

1. まず「何W必要か」を決める

充電器の出力（W＝ワット）は、つなぐ機器の中でいちばん電力を使うものに合わせて考えます。

機器の例 目安の出力
スマホ 20〜30W
タブレット 30〜45W
薄型ノートPC 45〜65W
高性能ノートPC 65〜100W以上

正確な数値は、使っている機器の公式サイトや付属充電器の表示で確認してください。足りないと「充電が遅い」「使いながらだと減っていく」状態になります。

自分に必要なW数の出し方（3ステップ）

  1. 同時に充電したい機器を書き出す（例：ノートPC＋スマホ）
  2. それぞれの「推奨W数」を、付属充電器のラベル（出力の欄）や公式サイトで調べる
  3. いちばん大きい機器のW数を「1ポートで出せる」ことと、全部足したW数が「合計出力」以内であることを確認する

付属充電器のラベルに「5V⎓3A／9V⎓3A／20V⎓3.25A」のように書かれていれば、いちばん大きい組み合わせ（この例なら20V×3.25A＝65W）がその機器向けの目安になります。

2. 複数ポートは「合計」と「1ポートあたり」を両方見る

複数ポートの充電器でいちばん多い失敗がここです。

  • 合計出力：全ポートを同時に使ったときの上限
  • 1ポートあたりの最大出力：1台だけつないだときに出せる上限

たとえば「合計65W」でも、2台同時につなぐと配分が変わり、ノートPC側が想定より少なくなることがあります。商品ページにあるポートごとの出力配分表を必ず確認しましょう。

配分表の読み方

配分表は多くの場合、次のような形で載っています（数値は読み方の説明用の例で、特定の製品のものではありません）。

つなぎ方 ポートA ポートB ポートC
Aだけ 最大◯W ー ー
A＋B ◯W ◯W ー
A＋B＋C ◯W ◯W ◯W

見るポイントは「ノートPCをつなぐポートに、同時使用時でも必要なW数が残るか」です。どのポートが高出力かは製品ごとに違うので、ノートPC用のポートを決めておくと迷いません。

また、製品によっては2台目を挿した瞬間に出力の割り振りをやり直すため、充電が一瞬止まることがあります。気になる場合は商品ページの説明や注意書きを確認しましょう。

3. 規格は「USB PD」対応を選ぶ

ノートPCやiPhone・Androidの多くは、USB Power Delivery（USB PD）という規格で急速充電します。迷ったらPD対応と書かれたものを選べば大きく外しません。

USB PDで電力が決まる仕組み

USB PDでは、充電器と機器がケーブル越しに「この電圧・電流なら出せます」「ではこれでお願いします」とやり取り（ネゴシエーション）してから電力を流します。電力は「電圧（V）×電流（A）＝W」で決まり、5V・9V・15V・20Vといった決まった電圧の中から、機器が対応できるものが選ばれます。

このため、大きいW数の充電器にスマホをつないでも、スマホが受け取れる分しか流れません。逆に、充電器・ケーブル・機器のうちいちばん弱いところで上限が決まります。

4. GaN（窒化ガリウム）って何がいいの？

GaNは充電器の中に使われる半導体の素材です。従来品より小さく・発熱しにくく作りやすいのが特徴で、同じW数でもコンパクトな製品が増えています。持ち歩くならGaN採用モデルが有利です。

5. ケーブルも忘れずに

充電器が高出力でも、ケーブルが対応していないと性能が出ません。

  • 60Wを超える充電には、100W（5A）対応と書かれたケーブルが必要
  • 安すぎるノーブランド品は避け、対応W数が明記されたものを選ぶ
ケーブルの表示 流せる電流の上限 向いている使い方
60W（3A）対応 3A（20Vで60W） スマホ・タブレット・薄型ノートPC
100W（5A）対応 5A（20Vで100W） 60Wを超えるノートPC
240W対応 5A（より高い電圧に対応） 100Wを超える機器向けの新しい規格に対応した製品

5A対応のケーブルには、流せる電流などの情報を充電器や機器に伝える小さなチップ（e-Marker）が入っています。見た目では区別できないので、パッケージや商品ページの「◯W対応」の表記で確認しましょう。なお、データ転送の速さ（USB 2.0／USB4など）と充電のW数は別の性能です。「充電は速いけれどデータ転送は遅い」ケーブルもあるので、目的に合わせて確認してください。

6. 安全面のチェック

  • 日本で販売される電源機器にはPSEマークの表示が必要です
  • 過電流・過熱保護などの記載があるかも確認しましょう

よくある質問（Q&A）

Q1. スマホ用の20W充電器でノートPCは充電できる？

機種によります。 USB PDで充電するノートPCの中には、低いW数でもゆっくり充電できるものがありますが、「充電されない」「使いながらだと電池が減る」という場合もあります。動作の条件はメーカーの公式情報で確認し、基本は付属充電器と同じかそれ以上のW数を選ぶのが安心です。

Q2. 大きいW数の充電器でスマホを充電しても大丈夫？

USB PDでは機器側が受け取れる電力を選ぶ仕組みなので、スマホが対応している分だけが流れます。W数が大きいこと自体を心配する必要は基本的にありません。ただし、PSEマークのない製品や、規格への対応がはっきりしない製品は避けましょう。

Q3. PPSって何？必要？

PPS（Programmable Power Supply）は、USB PDの中の機能で、電圧を細かく調整しながら充電できるものです。一部のAndroidスマホは、PPS対応の充電器でないと最大の速さが出ない場合があります。お使いのスマホの公式ページに「PPS」と書かれていれば、充電器もPPS対応を選ぶと安心です。iPhoneや多くのノートPCでは、通常のUSB PD対応で十分なことが多いです。

Q4. 「Quick Charge」と「USB PD」は同じ？

別の規格です。Quick Chargeは一部のAndroid機器で使われてきた急速充電の方式で、USB PDとは仕組みが違います。両方に対応した充電器もあるので、手持ちの機器に合わせて商品ページの対応規格を確認しましょう。

Q5. 充電器の「W数が大きい」ほど電気代も高くなる？

充電器のW数は「出せる上限」で、実際に使われる電力は、つないだ機器が必要とする分です。家電の電気代の考え方は家電の電気代計算ツールで、消費電力と時間を入れて目安を出せます。

Q6. 寝ている間の充電を止めたり、時間で切ったりできる？

充電器そのものにタイマーがなくても、コンセント側をスマートプラグにすると、スマホから電源のオン・オフや時間指定ができます。ただし、ノートPCなどは充電を急に切ってよいかを機器側の説明で確認してから使いましょう。

まとめ

  1. いちばん電力を使う機器に合わせてW数を決める
  2. 複数ポートなら配分表を見て、ノートPC用のポートに必要なW数が残るか確認
  3. USB PD対応、スマホがPPS対応ならPPSも、持ち歩くならGaN
  4. ケーブルの対応W数（60W／100W／240W）も合わせる
  5. PSEマークと保護機能の記載をチェック
