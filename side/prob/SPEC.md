# 確率のお話シリーズ（3分・縦）制作仕様（2026-11-27 オーナー指示）

オーナーの指摘（2026-11-27）：「とっても分かりにくい」「1万人で検証と言いながら100人。アホか」「吸収したやつを使って、もっと分かりやすく」。
→ **分かりやすさが最優先**。下の決まりは全部守る。迷ったら「中学生が1回見て分かるか」で決める。

## 分かりやすさの決まり（いちばん大事）
1. **1画面＝1つのこと、数字は大きく1つまで**（補足の数字は小さく1つまで）。表・数字の羅列はしない
2. **言った数と見せる数を一致させる**。「1万回」と言ったら**1万個の点（100×100）**を見せる（`lib/dots.js`）。縮めて見せるなら「100回だけ見てみると」とはっきり言う
3. **まず1回やってみせる**（扉を1つ開ける／じゃんけん1回／くじを1本ずつ引く）→ 10回 → 100回 → 1万回、と段階的に増やす
4. **理由は図1枚**で。言葉だけの説明をしない
5. 話す文は短く（1文15〜20字）。専門用語・カタカナ語を使わない（「確率」はOK。「期待値」「収束」は使わない）
6. 答えは「ためてから」出し、出したら**2.5秒以上止める**（画面も音も）
7. 字幕は2行まで、画面のパネルと重ねない。アリスと重ねない
8. 色の意味を固定：当たり・勝ち＝金色、外れ＝灰色、比べる2つ＝赤と青
9. 冒頭3秒に問い。最後は冒頭の問いに答えて終わる
10. 計算は本物（Python・乱数の種を固定・1万回以上）。理論値（計算で出る答え）と並べて一致を確かめ、画面にも小さく出す
