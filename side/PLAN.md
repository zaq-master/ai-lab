# 新しい副業：計画書（2026-11-17）

ブログ（QOLガジェット研究所）とは別の事業。条件は「基本無料」「ジャンルは問わない」「AIが考えて組む」。

## 1. 前の事業から分かったこと
- 2週間で売上 **¥0**。原因は商品ではなく**入口**：Googleに載らず（0件）、SNSはPCが切れると止まる
- なので今回は **「買う人がすでに集まっている売り場」** に置く（LINEスタンプショップ・SUZURI）。検索やSNSで人を集めなくても、売り場の中で見つけてもらえる

## 2. ジャンルの検討（言われた候補すべて）
| 候補 | 判定 | 理由 |
|---|---|---|
| **LINEスタンプ** | ◎ 採用 | 出品無料。日本でいちばん人が多い売り場。文字だけのスタンプは定番ジャンル。AI利用そのものは不承認の理由ではない（第三者の権利侵害が見られる。申請時に「AI使用」を選ぶと表示される、という解説あり※公式で要確認） |
| **SUZURI** | ◎ 採用 | 出品無料・在庫なし。同じデザインでTシャツ・ステッカー等を一度に作れる。売れた分だけ、自分で決めた上乗せ額が入る |
| AI動画（YouTube・TikTok） | △ 後回し | 無料で作れるが、YouTubeの収益化は登録者1,000人などの条件があり、お金になるまで数ヶ月以上 |
| 投資 | ✕ | 元手（お金）が要る＝「基本無料」に合わない。他人への有料の投資助言は登録が必要な業種 |
| アダルト | ✕ | AIでは作らない。販売サイトの規制が厳しく、AI作品の受付停止も起きている。アカウント停止・決済停止のリスクが高い |
| ストック素材（PIXTA等） | ✕ | PIXTAは2026年4月にAI生成作品の新規受付を終了、5月に販売も停止（報道ベース） |

## 3. 作ったもの：「でか敬語」
大きな文字の丁寧なひと言（承知しました／今から帰ります／ご飯いります…）40種。
仕事・家族・友だちのどれでも使え、絵柄の好みが分かれにくい。

- **画像生成AIは使っていない**：フォント（IPAゴシック、画像の販売可）で描くだけ。似た絵・権利侵害の心配がほぼない
- 作り直し・別シリーズ追加は `python3 side/dekakeigo/make.py`（文字と色の一覧を書き換えるだけ）

| ファイル | 中身 |
|---|---|
| `side/dekakeigo/out/line_stickers.zip` | LINE申請用 一式（スタンプ40個 370×320・メイン画像 240×240・タブ画像 96×74、背景透過） |
| `side/dekakeigo/out/suzuri/01〜40.png` | SUZURI用（2400×2400 背景透過） |
| `side/dekakeigo/out/preview.png` | 一覧（確認用） |

## 4. オーナーにやってほしいこと（合計 約40分・お金はかからない）
アカウント作成・規約への同意・振込先の登録は、AIはやらないルールなのでお願いします。

### ① LINEスタンプ（約25分・PCがおすすめ）
1. LINE Creators Market（creator.line.me）にLINEアカウントでログインし、クリエイター登録
2. 「新規登録」→ スタンプ → 下の文をそのまま入力
   - タイトル：でか敬語
   - 説明文：大きな文字で読みやすい、丁寧なひと言スタンプ。仕事にも家族にも使えます。
   - 販売価格：120円（いちばん安い価格。最初は数を売る）
   - AIの使用：**「あり」を選ぶ**（絵は画像生成AIではなくフォントで描いたが、言葉選びとプログラムをAIが作ったため。隠さない方針）
3. 「スタンプ画像」→ ZIPアップロード → `line_stickers.zip` を選ぶ → 「リクエスト」
4. 審査は数日〜。承認されたら「リリース」を押す（自動リリースにしておくと手間なし）

### ② SUZURI（約15分・スマホアプリでOK）
1. SUZURI（suzuri.jp）に無料登録
2. `suzuri/` の画像を1枚ずつアップ（まず人気が出そうな10枚：01・05・07・08・13・17・21・26・33・36）
3. 作るグッズ：Tシャツ・ステッカー・スマホケース・マグカップ
4. 上乗せ額（トリブン）：Tシャツ **500円**、ステッカー **100円**、その他 **300円**
5. 説明文：「大きな文字の丁寧なひと言。AIが書いたプログラムでフォントを描いて作ったデザインです。」

## 5. 現実的な見通し（正直に）
- LINEスタンプ120円が1つ売れると、作者の取り分は**数十円**（公式の分配率は要確認）。SUZURIはTシャツ1枚で**500円**
- 1シリーズで大きく稼ぐのは難しい。**シリーズを増やして売り場に並ぶ数を増やす**のが勝ち筋（作るのはAIが数分でできる）
- 判断基準：**出してから30日で売上0なら、文字の内容（ジャンル）を変える**。売れたシリーズは関連シリーズを増やす

## 6. 次の一手（AI側）
- 第2弾の候補：推し活の敬語／介護・看護の現場のひと言／関西弁の敬語（売れ行きを見て1つ選ぶ）
- SUZURIは公式API（自動出品の仕組み）があるが、この作業環境からSUZURIのサイトにつながらない。オーナーがAPIキーを発行し、つながる設定を許可してくれれば、新デザインの出品まで自動化できる
