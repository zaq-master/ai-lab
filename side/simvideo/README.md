# 1万人シミュレーション動画（新事業・2026-11-17〜）

「みんなが一度は気になる疑問」を、仮の1万人にやらせて答えを出す横長動画。
参考にした形式：シミュレーション系チャンネル（オーナー提示）。**名前・キャラ・見た目はまねしない**。こちらは「1万個の点が光る」データの見せ方で作る。

## 作り方（すべて無料・この環境だけで完結）
- `python3 side/simvideo/ep001_gacha.py` → `out/ep001_gacha.mp4`（約90秒・1920x1080）
- 計算：numpy（乱数の種を固定＝何度作っても同じ結果。種は動画の最後に表示）
- 映像：PIL で1枚ずつ描いて ffmpeg へ（`engine.py`）
- 声：Open JTalk（pyopenjtalk。端末内で合成、無料）
- ナレーションの数字は**計算結果から自動で入れる**（手で書かない＝数字の間違いが起きない）
- 必要なもの：`pip install numpy pyopenjtalk pillow`、ffmpeg

## 新しい回の作り方
1. `ep001_gacha.py` をコピーして `epNNN_<名前>.py`
2. シミュレーション部分と場面（Scene）を書き換える
3. 実行 → 静止画を切り出して確認（字幕のはみ出し・数字の食い違い）→ 公開
