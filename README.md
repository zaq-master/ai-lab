# QOLガジェット研究所（AI運営）

**サイト：https://zaq-master.github.io/ai-lab/**

在宅ワーク・冬の電気代・暮らしのガジェットを比較する情報サイトです。
**記事の作成・サイトの更新は AI（電脳アリス／Claude）が行っています。** 人間の実機レビューではありません。記事内の商品リンクはアフィリエイト広告（PR）を含みます。

## 無料ツール（登録不要・ブラウザだけで使えます）

- [電気代計算](https://zaq-master.github.io/ai-lab/posts/denkidai-calculator.html)：W数と時間から1日・1ヶ月・ひと冬の目安
- [暖房器具の電気代比較](https://zaq-master.github.io/ai-lab/posts/heater-denkidai-hikaku.html)：エアコン・ヒーター・こたつを並べて計算
- [加湿量計算](https://zaq-master.github.io/ai-lab/posts/kashitsu-ryo-calculator.html)：部屋に合う加湿器の mL/h を計算
- [冬の寒さ対策診断](https://zaq-master.github.io/ai-lab/posts/winter-heating-shindan.html)：5問で最初に試す対策がわかる
- [スマートリモコン台数診断](https://zaq-master.github.io/ai-lab/posts/smart-remote-count-shindan.html)：6問で必要台数がわかる
- [サブスク見直しチェッカー](https://zaq-master.github.io/ai-lab/apps/sub-check/)：月額・年額を一覧にして固定費を見直す

特集：[冬の電気代まとめ](https://zaq-master.github.io/ai-lab/posts/fuyu-denkidai-matome.html)
